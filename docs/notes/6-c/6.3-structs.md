## What is a struct?

A `struct` in C let's you define a blueprint for creating a collection of variables.

Consider a program that gather information about boxes:

```c
#include <cs50.h>
#include <stdio.h>

int main()
{
    float width = get_float("Enter width: ");
    float height = get_float("Enter height: ");
    float depth = get_float("Enter depth: ");
    int color = get_int("Enter color code: ");
    bool transparent = get_int("Is this box transparent (0/1)?: ");

    // ...

    return 0;
}
```

There are five properties associated with a box. If you want to track the information about multiple boxes, you have to create multiple copies of these variables.

```c
#include <cs50.h>
#include <stdio.h>

int main()
{
    float box1_width = get_float("Enter width: ");
    float box1_height = get_float("Enter height: ");
    float box1_depth = get_float("Enter depth: ");
    int box1_color = get_int("Enter color code: ");
    bool box1_transparent = get_int("Is this box transparent (0/1)?: ");

    // ...

    float box2_width = get_float("Enter width: ");
    float box2_height = get_float("Enter height: ");
    float box2_depth = get_float("Enter depth: ");
    int box2_color = get_int("Enter color code: ");
    bool box2_transparent = get_int("Is this box transparent (0/1)?: ");

    // ...

    return 0;
}
```

With a `struct`, you can create a reusable blueprint that bundles multiple variables up into a single object.

```c
#include <cs50.h>
#include <stdio.h>

// Define the struct (the "blueprint")
struct box {
    float width;
    float height;
    float depth;
    int color;
    bool transparent;
};

int main()
{
    struct box box1;
    box1.width = get_float("Enter width: ");
    box1.height = get_float("Enter height: ");
    box1.depth = get_float("Enter depth: ");
    box1.color = get_int("Enter color code: ");
    box1.transparent = get_int("Is this box transparent (0/1)?: ");

    // ...

    struct box box2;
    box2.width = get_float("Enter width: ");
    box2.height = get_float("Enter height: ");
    box2.depth = get_float("Enter depth: ");
    box2.color = get_int("Enter color code: ");
    box2.transparent = get_int("Is this box transparent (0/1)?: ");

    // ...

    return 0;
}
```

You can pass that collection of variables to another function:

```c
void print_box_info(struct box b)
{
    printf("%f x %f x %f\n", b.width, b.height, b.depth);
    // ...
}

int main()
{
    struct box box1;
    // ...
    print_box_info(box1);
}
```
