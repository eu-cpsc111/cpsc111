## Create a Function

In Python, we used the `def` keyword to create a function:

```python
def my_function():
    print("This is my function!")
```

In C, the syntax is slightly different. Here is a function _definition_:

```c
void my_function()
{
    printf("This is my function!\n");
}
```

- `void` - this function does not return a value. You can change this to match whatever data type you want to return from this function (`int`, `float`, etc.).
- `my_function` - this is the name of the function. Naming rules are similar to Python.
- `()` - this is the parameter list for the function. In this example, there are no parameters.
- `{ }` - any code that is part of the function must go in between two curly braces. This is the function body.

In C, you must have a `main()` function. This is the entry point into the program.

```c
int main()
{
    // Your code goes here...

    return 0;
}
```

- The `main()` function is called automatically when your program runs.
- Your code can call any other function you create.

Let's put this together into an example program:

```c
#include <stdio.h>

void my_function()
{
    printf("This is my function!\n");
}

int main()
{
    my_function();
    my_function();
    my_function();
    return 0;
}
```

Here we call `my_function()` three times in a row. Calling a function will trigger that function to execute before continuing on in the program.

## Parameters

To specify input parameters for a function, put them inside of the parentheses.

```c
void my_function(int points_earned, int points_possible)
{
    printf("You earned %d out of %d points.\n", points_earned, points_possible);
}
```

- The parameter list is a comma-separated list of variables.
- Each parameter has a data type (like `int`, `float`, `char`, etc.) and a name.
- The example above has two parameters:
  - `points_earned`
  - `points_possible`
- You can use the parameters inside the function body just like any other variable.

Here's an example program using this function:

```c
#include <stdio.h>

void my_function(int points_earned, int points_possible)
{
    printf("You earned %d out of %d points.\n", points_earned, points_possible);
}

int main()
{
    my_function(10, 20);
    my_function(20, 20);
    my_function(5, 15);
    return 0;
}
```

- When calling a function, put the values you want to input into the function in the same order as the parameter list.
- For example, in the function call `my_function(10, 20);`:
  - `10` will be copied into the `points_earned` parameter.
  - `20` will be copied into the `points_possible` parameter.

## Return Values

The first symbol in a function definition is the return data type. What type of data does this function return?

A `void` return type means the function does not return any data at all. It will execute code, then return back to the caller, but will not provide any return value.

Here's an example:

```c
#include <stdio.h>

void my_function()
{
    printf("Hello there!\n");
}

int main()
{
    my_function();
    return 0;
}
```

Here's an example of a function that returns an integer value:

```c
int get_area(int width, int height)
{
    return width * height;
}
```

The caller will receive the return value after the function is called.

```c
#include <stdio.h>

int get_area(int width, int height)
{
    return width * height;
}

int main()
{
    int area = get_area(10, 20); // <-- Caller gets return value from function
    printf("The area is %d.\n", area);
    return 0;
}
```

You can have multiple return statements in a function:

```c
int get_points(int code)
{
    if (code == 200) {
        return 2;
    }

    if (code == 300) {
        return 3;
    }

    if (code == 400) {
        return 4;
    }

    return 0;
}
```

- `return` will return from the current function.
- You have to use `return` from within a function.
- `return` can be used within branches; it will do the same thing.

If a function does not have a return value, you don't have to use the `return` statement:

```c
void do_something()
{
    printf("Hello\n");
    printf("World!\n");
}
```

However, sometimes you make want to exit a function early. You can still use the `return` statement, just don't specify any value to return:

```c
void execute(int timer)
{
    if (timer > 30) {
        return;
    }

    printf("Executing action...\n");
}
```
