## `while` Loops

In Python, we saw `while` loops that repeat a block of code as long as some condition hold true.

```python
x = 0
while x < 5:
    print(x)
    x += 1
```

C also has support for `while` loops:

```c
int x = 0;
while (x < 5) {
    printf("%d\n", x);
    x += 1;
}
```

Differences from Python:

- Parentheses around loop test .
- Curly braces around loop body.

The syntax should feel similar to C's `if` syntax.

In previous examples, sometimes we intentionally created a loop test that always evaluates to true. In C, keep in mind that any non-zero value evaluates to true.

_What does this program do?_

```c
#include <cs50.h>
#include <stdio.h>

int main()
{
    while (1) {
        int x = get_int("Enter a number: ");
        if (x > 0) {
            printf("You entered %d.\n", x);
        }
        else {
            break;
        }
    }

    return 0;
}
```

## `do...while` Loops

C has an alternate version of the `while` loop:

```c
int x = 0;
do {
    printf("%d\n", x);
    x += 1;
} while (x < 5)
```

- Executes loop body first, then evaluates the loop test.
- Inverted from regular `while` loop.

## `for` Loops

The `while` loop in C is very similar to the `while` loop in Python.

The `for` loop in C is very different than the `for` loop in Python.

Here is the general form of the `for` statement:

```
for (initialize; test; step) {
    statement
}
```

- _initialize_ - this expression is evaluated once. It's the first thing the `for` loop does. Often this is used to initialize some variable.
- _test_ - this is evaluated _before_ the loop body executes. If true, the loop body executes. If false, the loop ends and the program continues with the code after the `for` statement.
- _step_ - this is evaluated _after_ the loop body executes (after each iteration of the loop).

### Example 1

Here's an example:

```c
for (int i = 0; i < 3; ++i) {
    printf("i: %d\n", i);
}
```

- _initialize_ is `int i = 0`
- _test_ is `i < 3`
- _step_ is `++i` (this is shorthand for `i += 1`; increment `i` by 1)

Here's a play-by-play:

- `for` loop starts.
- _initialize_ expression evaluated: `int i = 0`
  - This creates a new variable `i` and sets it to 0.
- _test_ expression evaluated: `i < 3`
  - Is 0 less than 3? Yes.
- Iteration 1:
  - Loop body executes.
    - The `printf()` statement executes.
    - End of first iteration.
  - _step_ expression evaluated: `++i`
  - `i` is incremented by 1, so `i` now equals 1.
  - _test_ expression evaluated: `i < 3`
  - Is 1 less than 3? Yes

- Iteration 2:
  - Loop body executes.
    - The `printf()` statement executes.
    - End of second iteration.
  - _step_ expression evaluated: `++i`
    - `i` is incremented by 1, so `i` now equals 2.
  - _test_ expression evaluated: `i < 3`
    - Is 2 less than 3? Yes

- Iteration 3:
  - Loop body executes.
    - The `printf()` statement executes.
    - End of third iteration.
  - _step_ expression evaluated: `++i`
    - `i` is incremented by 1, so `i` now equals 3.
  - _test_ expression evaluated: `i < 3`
    - Is 3 less than 3? No

- For loop ends.

### Example 2

This loop prints a list of numbers from 1 to 10 (inclusive):

```c
for (int i = 1; i <= 10; ++i) {
    printf("%d\n", i);
}
```

- Pay close attention to the _test_ expression.
  - In this example, `<=` is used.
  - Watch out for off-by-one errors. Use the correct _test_.

This code does the exact same thing. _What is the difference between these two variations?_

```c
for (int i = 1; i < 11; ++i) {
    printf("%d\n", i);
}
```

### Example 3

For loops are very flexible. You have a lot of control over the different expressions.

This example increments the counter variable by 2 instead of 1:

```c
for (int i = 1; i <= 10; i = i + 2) {
    printf("%d\n", i);
}
```

### Example 5 - Strange Loops

The three expressions in the `for` loop are actually not required. This can lead to some strange looking (but valid) loops.

```c
int x = 5;
for ( ; x < 10; ) {
    printf("%d\n", x);
    x++;
}
```

- You could easily rewrite this into a `while` loop.

_What do you think this code does?_

```c
for (;;) {
    printf("Hi\n");
}
```

### Example 6 - The Semi-colon

_What is the output of this code?_ (Pay close attention to the semi-colon!)

```c
for (int i = 1; i < 4; ++i);
    printf("%d ", i);

printf("done\n");
```

## `break` and `continue`

These statements do the same thing as in Python (just with a semi-colon at the end).

```c
while (1) {
    int x = get_int("Enter a number: ");
    if (x > 0) {
        printf("You entered %d.\n", x);
    }
    else {
        break;
    }
}
```

```c
for (int i = 1; i <= 100; i++) {
    if (i % 3 == 0) {
        continue;
    }

    printf("%d\n", i);
}
```

## Nested Loops

You can put loops inside of loops (loop inception!)!

```c
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 5; j++) {
        printf("%d, %d\n", i, j);
    }
}
```

A common example might be looping over a 2D structure like a grid or matrix.

```python
for (int row = 0; row < 5; row++) {
    printf("Row %d: ", row);
    for (int col = 0; col < 5; col++) {
        printf("%d ", col);
    }
    printf("\n");
}
```

- The inner `for` loop is part of the loop body (code block) for the outer `for` loop.
- You should get comfortable with nested loops like this. It will come in handy in a future assignment!
