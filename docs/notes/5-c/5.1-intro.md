## Hello, worlds!

Python:

```python
print("Hello, world!")
```

C:

```c
#include <stdio.h>

int main()
{
    printf("Hello, world!\n");
    return 0;
}
```

## Welcome to C

Let's look more closely at the C code for the "Hello, world!" program. There are immediate differences between C code and the Python code you've been writing up to this point.

Let's take it line by line:

```c
#include <stdio.h>
```

In Python, you could import code from other Python modules. This included the Python standard library.

C has a similar feature. It works differently than Python, but the idea is generally the same. We want to get access to code that is stored somewhere else. The mechanics of how this works is more complicated in C. We won't go into detail right now though.

This particular line is including the `stdio` header file from the C standard library.

- C also has a standard library of built-in functions you can use.
- "Header files" are used to share code between files. More details to come later on how this actually works.
- The `stdio.h` header file is for "standard I/O". This gives us access to the `printf()` function that is used in this program.

```c
int main()
{
   ...
}
```

This defines a function named `main()`. The `int` in front of `main()` tells the compiler this function will return an integer. More on data types later.

In Python, we could start writing code in a `.py` file and run it, no problem.

In C, you have to declare a `main()` function. Your program starts by executing code in this function. This is the "entry point" of the program. Your program _must_ have a `main()` function, otherwise compilation will fail.

Functions in C are wrapped with curly braces: `{` and `}`. All your code for that function must be placed inside the braces.

```c
printf("Hello, world!\n");
```

This line might seem a little more familiar to you coming from Python - but maybe just a little.

Notice the function is named `printf` and not `print`.

Notice the `\n` inside the string. The `printf()` function does not automatically put a newline character at the end of what you print. You have to do that explicitly. (Python's `print()` is the opposite.)

Notice the `;` at the end of the statement. **Statements in C must end with a semi-colon.** There are some lines of code that don't require a semi-colon, but most do. It is a very common error to forget a semi-colon at the end of a statement!

```c
return 0;
```

This returns the integer value 0 from the `main()` function.

We know about returning values from functions already from Python. The same idea applies in C.

The interesting part here is that this return is coming from the `main()` function, which will cause the program to end. The value returned here is used as the program's _exit code_. A value of 0 means the program indicates it ran successfully. Sometimes programs will return different values to indicate certain types of errors.

## Basic Output

`printf()` is different from Python's `print()`. We'll explore the behavior of `printf()` now.

### Whitespace

- First parameter: a format string. The format of what you want to print out.
- Additional parameters: values to plug into the format string.

The simplest use of `printf()` is passing a simple string with no other parameters:

```c
printf("Hello, world!");
```

Compare the output of the above line with this line below:

```c
printf("Hello, world!\n");
```

- This line includes a newline character `\n` at the end of the line.
- What difference do you see in the output?

Next, try using multiple `printf()` statements in a row:

```c
printf("Hello");
printf(",");
printf(" world!\n");
```

- Pay close attention to placement of spaces.

What's up with `\n`?

- "Escape sequence" - allow you to place special, non-printable characters inside strings.
- Non-printable characters include newline `\n`, tab `\t`, and [more](https://en.wikipedia.org/wiki/Escape_sequences_in_C).

What do you think about this line?

```c
printf("Hello\n\n\n\nworld\n\n\n\n\n!\n");
```

### Format Specifiers

In Python, you could do:

```python
print(2 * 10)
```

If you try this in C, you will get a compilation error:

```c
printf(2 * 10);
```

If you want to do this in C, you have to take advantage of `printf`'s formatting features (hence the "f" in the name).

```c
printf("%d", 2 * 10)
```

- First parameter is a format string. You can insert _format specifiers_ into the format string. Each specifier is replaced by an additional parameter passed into `printf()`.
- `%d` specifies a decimal integer. You must pass an integer as an additional parameter.

```c
printf("The number %d is an integer.\n", 2 * 10);
```

- Use the format specifiers to place values in particular locations inside the string.

```c
printf("The numbers, %d, %d, and %d are integers.\n", 2 * 10, 15, 17 + 2);
```

- The order of the additional parameters is important!

What format specifiers are available?

- Check out the [printf man page](https://man7.org/linux/man-pages/man3/printf.3.html).
- The common ones you should know:
  - `%d` - decimal integer (`%i` does the same thing)
  - `%s` - a string
  - `%c` - a character
  - `%f` - a double/float (floating-point number)

The type of data you pass into `printf()` _must_ match the format specifiers you include.

Try running this code:

```c
printf("Name: %s\nAge: %d\n", 21, "Alice");
```

- Can you fix this code?

Format specifiers become most useful when using variables.

```c
int age = 21;
const char* name = "Alice";
printf("Name: %s\nAge: %d\n", name, age);
```

We'll talk more about variables soon enough.

### Where does it go?

Operating systems provide input and output abstractions for programs to use. For example, the [standard streams](https://en.wikipedia.org/wiki/Standard_streams).

- Standard input, standard output, standard error
- Often listed as `stdin`, `stdout`, `stderr`
- When you use `printf()`, the text is sent to standard output

Standard output will default to going to the terminal window where you run the program. That's how you see the program output when you run it.

```
./src/lecture.bin
```

You can _redirect_ standard output to go other places. For example, to a file:

```
./src/lecture.bin > file.txt
cat file.txt
```

You can pipe output from one program into the input of another:

```
./src/lecture.bin | grep 'Age'
```

## Whitespace in Code

Python code required strict formatting when it came to lines and indentation.

```python
if a > 5:
    print("A")
    for i in range(0, 2):
        print(i)
```

- If you mis-align the statements, you may get incorrect behavior or an error.

In C, whitespace is ignored by the compiler.

For example, here is some C code that is equivalent to the Python code above.

```c
int a = 6;
if (a > 5) {
    printf("%d", a);
    for (int i = 0; i < 2; i++) {
        printf("%d", i);
    }
}
```

Here is the same C code, but written a little differently.

```c
    int a = 6;    if (a > 5)
{printf("%d", a);for (int i = 0; i < 2; i++) {
            printf("%d", i);}}
```

- This code is identical to the previous code. The only difference is whitespace.
- The behavior of the two examples are identical.

**Formatting your code legibly is still important.**

- Just because you _can_ write a whole program on one line, doesn't mean you _should_.

## Comments

Single line comments:

```c
// Single line comment
//printf("Hello, world!\n");
printf("ABC\n"); // printf("DEF\n");
```

Multi-line comments:

```c
/*
Everything in here is ignored.
printf("Hello!\n");
printf("World!\n");
*/

/* printf("Hello\n"); */
printf("ABC\n"); /* printf("DEF\n"); */
```

## Errors

In Python sometimes you wrote code with errors 😭. In C, you can most definitely write code with errors 🔥.

Let's review the three categories of errors:

**Syntax errors** (or compilation errors) - the compiler fails because your code is written improperly. It doesn't follow the syntax rules of the language.

Can you spot the syntax error below?

```c
printf("Hello, world\n!")
```

In C, you'll want to get comfortable reading the compiler's output. It will show you where syntax errors have occurred and may offer hints as to what's wrong.

**Logic errors** - your program compiles and runs file, but the output is not what you expect.

Here is a logic error:

```c
int width = 20;
int height = 10;
printf("Area: %d", width * width);
```

**Runtime errors** - your program compiles and runs, but at some point it crashes (for various possible reasons, maybe your program ran out of memory).
