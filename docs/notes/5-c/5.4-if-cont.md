## Compound Conditions

Sometimes you want multiple things to be true before taking a particular branch:

```c
int num = 5;
if (num < 10 && num > 0) {
    printf("In range.\n");
}
else {
    printf("Out of range.\n");
}
```

You can use logical operators to combine different Boolean expressions:

```c
int num = 5;
if (num > 10 || num == 5) {
    printf("Valid.\n");
}
else {
    printf("Invalid.\n");
}
```

Another example:

```c
int isSystemArmed = 1;
int isMotionDetected = 1;

if (isSystemArmed && isMotionDetected) {
    printf("Motion was detected. Alarm will sound.\n");
}
else if (isSystemArmed) {
    printf("System is armed, but no motion detected.\n");
}
else if (isMotionDetected) {
    printf("Motion detected, but system not armed.\n");
}
else {
    printf("System not armed; no motion detected.");
}
```

## Nested Ifs

You can have nested branches of code.

```c
int isSystemArmed = 1;
int isMotionDetected = 1;

if (isSystemArmed) {
    printf("System is armed.\n");
    if (isMotionDetected) {
        printf("Motion detected.\n");
        printf("Alarm will sound.\n");
    }
    else {
        printf("No motion detected.\n");
    }
}
```

You can create as many levels of nesting as you want. But things start to get hard to read.

Try making sense of this:

```c
int x = 105;
if (x > 5) {
    if (x > 10) {
        if (x > 50) {
            if (x > 100) {
                printf("Greater than 100.\n");
            }
        } else {
            printf("Not greater than 50.\n");
        }
    } else if (x == 7) {
        printf("x is 7.\n");
    }
}
```

## Curly Braces

Consider this code:

```c
if (1 == 1)
    printf("Everything is okay.\n");
```

Notice anything? There are no curly braces. This is valid C code.

"Wait!" you might say. "I thought C required curly braces for if statements!"

You might then try this code:

```c
if (1 != 1)
    printf("Uh-oh.\n");
    printf("Something went wrong.\n");
```

This code compiles without errors. But does it do what you think it does?

C allows `if` statements to omit braces, but it will treat _only the single next statement_ as part of the if block. The code above is equivalent to:

```c
if (1 != 1) {
    printf("Uh-oh.\n");
}
    printf("Something went wrong.\n");
```

This can be a source of bugs if you are not familiar. Pay close attention. Some developers prefer to _always_ use curly braces around if statements to avoid situations like this.

Here's another example. _What is output by the following code?_

```c
char command = 'b';
int param = 10;

if (command == 'a')
    if (param > 10)
        printf("Y is too high.\n");
else if (command == 'b')
    printf("Executing command B.\n");
else
    printf("Invalid command.\n");

printf("End of program.\n");
```

## Arithmetic Expressions

Let's talk a little more about arithmetic expressions in C.

An _assignment_ has the following syntax:

```
target = expression;
```

- `target` is a variable you want to assign a value to.
- `expression` is the new value you want to assign. It can be, for example, a literal value, a single variable, a mathematical computation, etc.

### Basic Operators

An _operator_ is a symbol that performs some kind of calculation. We've already mentioned the basic arithmetic operators in C:

```c
int x = 0;
int y = 100;
x = y + 12; // Addition
x = y - 12; // Subtraction
x = y * 12; // Multiplication
x = y / 12; // Division
x = y % 12; // Modulo
```

Expressions can be used in assignments as well as other places:

```c
int x = 100;
printf("%d\n", x + 12);
printf("%d\n", x - 12);
printf("%d\n", x * 12);
printf("%d\n", x / 12);
```

The minus `-` sign can be used for negation as well:

```c
int x = 100;
x = -100;
x = -x;
printf("%d\n", x);
printf("%d\n", -x);
printf("%d\n", x); // note how x was not changed in previous statement
```

There are some differences between mathematic notations and C++ expressions to be aware of:

```c
int x, y;
x = 5y; // Invalid, must use a multiplication operator (*)
x = xy; // Invalid, same as above
```

### Evaluation

Order of operations is similar to mathematical order of operations.

- Evaluate inside `()` parentheses first.
- `-` (negation)
- `*`, `/`, `%`
- `+`, `-`
- left-to-right

## Compound Assignments

Compound assignments combine both an assignment and simple expression into one statement.

Consider this code:

```c
int x = 5;
x = x + 2;
```

The second line could be simplified with a compound assignment.

```c
int x = 5;
x += 2;     // Shorthand for x = x + 2;
```

Can do this with other operators:

```c
int x = 2;
x = x + 2;
x += 2;         // x = x + 2
x -= 2;         // x = x - 2
x *= 2;         // x = x * 2
x /= 2;         // x = x / 2

int y = 4;
x -= y - 1;
```

## Integer Division

When dividing two integers (literals or variables), the result is the **quotient** of the division.

Consider $14 / 2$.

- Quotient is 7.
- Remainder is 0.

In C++:

```c
int x = 14 / 2;    // Result is 7 as expected
```

Consider $14 / 5$

- Quotient is 2.
- Remainder is 4.

In C:

```c
int x = 14 / 5;    // Result is 2
```

You might expect `14 / 5` to yield `2.8`. But when dealing with _integers_, the result does not have a fractional component. We'll look at floating-point numbers later.

What will the following code output?

```cpp
int halfWidth = (1 / 2) * width;
```

- Pay close attention!

## Modulo

The modulo operator `%` will perform integer division, but return the **remainder** of the division.

Consider $14 / 5$

- Quotient is 2.
- Remainder is 4.

In C++:

```c
int x = 14 % 5;    // Result is 4
```

Example of using modulo to wrap around a set of values:

```c
const int MAX_SPACES = 10;
int diceRoll = 12;
playerPos = (playerPos + diceRoll) % MAX_SPACES;
```

Example of using modulo to check divisibility:

```c
int x = y % 2;    // If result is 0, then y is divisible by 2 (and is an even number)
int x = y % 3;    // If result is 0, then y is divisible by 3
```
